# LeBass (르바스) - 프리미엄 당구 스코어보드 앱 🎱✨

**LeBass**는 React Native 및 Expo(v57) 기반으로 구축된 최첨단 **디지털 당구 스코어보드 애플리케이션**입니다.  
VisionOS 및 Spatial UI 스타일의 미학적 글래스모피즘(Glassmorphic) UI/UX를 적용하여 미래지향적이고 고급스러운 경기 스코어링 경험을 제공합니다.

---

## 🌟 주요 특징 (Key Features)

- **💎 VisionOS / Spatial UI 글래스모피즘 디자인**
  - 모던하고 세련된 반투명 아크릴 유리에 빛과 그라데이션을 결합한 스파셜 인터페이스.
  - 몰입감을 높여주는 시각적 조명 애니메이션 효과 및 그라데이션 백드롭.

- **🎞️ 실시간 플립 카드 애니메이션 (Flip Digit Animation)**
  - 숫자가 넘어가는 실물 스코어판 느낌을 재현한 3D 롤링/플립 애니메이션.
  - 점수 증감 시 시각적인 손맛을 선사하는 플립 카드 효과 적용.

- **🎮 맞춤형 당구 경기 모드 지원**
  - 3구 / 4구 / 포켓볼 등 경기 종목에 따른 점수판 세팅 지원.
  - 플레이어별 목표 점수(핸디), 이닝 타이머, 제한 시간 관리 기능.
  - 턴 전환 및 공격/수비 이닝 실시간 추적.

- **⏸️ 턴 & 일시정지 오버레이 및 제어**
  - 경기 일시정지 시 화면 중앙에 시각적인 일시정지(PAUSED) 오버레이 표시.
  - 점수 리셋, 선공 변경, 턴 넘기기, 이닝 취소/되돌리기 등 직관적인 하단 컨트롤 바.

- **👥 플레이어 관리 및 세팅 모달**
  - 선수 등록/선택 및 닉네임, 프로필, 핸디 점수 손쉬운 변경.
  - 경기 목표 점수 및 타이머 설정을 커스텀할 수 있는 경기 설정 모달 제공.

## 🛠️ 기술 스택 (Tech Stack)

- **Framework**: React Native 0.86.0, Expo v57.0.8 (Expo Router v57)
- **UI & Animations**: `react-native-reanimated` 4.5.0, `expo-blur`, `expo-glass-effect`, `react-native-gesture-handler`
- **Language**: TypeScript 6.0
- **Styling**: React Native StyleSheet, Custom Glassmorphism UI Components

## 🚀 시작하기 (Getting Started)

### 1. 의존성 패키지 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
# Expo 개발 서버 시작
npx expo start
```

### 3. 플랫폼별 실행 방법

- **iOS Simulator**: 터미널에서 `i` 키 입력 또는 `npm run ios`
- **Android Emulator**: 터미널에서 `a` 키 입력 또는 `npm run android`
- **Web Browser**: 터미널에서 `w` 키 입력 또는 `npm run web`

## 📅 업데이트 내역 (Changelog)

### 2026-08-03
- **플레이어 스탯 카드 반응형 레이아웃 개선**: 경기 인원이 4인 이상이 되어 2열 배치(Multi-Row)가 될 때, 득점 스코어(메인 점수)를 카드의 가로 중앙 정렬로 온전히 고정하고, 우측 스탯 정보(최근득점, 이번이닝, 에버리지, 하이런) 영역을 absolute absolute 포지셔닝 기반의 **2행 2열 격자(Grid) 구조**로 독립적으로 우측에 배치하여 가독성과 밸런스를 모두 극대화.
- **Metro 번들러 설정 고도화**: macOS의 `._*` 임시 메타데이터 파일이 재생성되어 빌드가 터지는 현상을 방지하기 위해 `metro.config.js`에 `blockList` 차단 필터를 추가하여 빌드 안정성 확보.
- **macOS 메타데이터 파일 정리**: 외장하드 환경에서 빌드를 방해하던 `._` 형태의 임시 파일(예: `._index.tsx` 등)들을 재귀적으로 삭제하여 Expo 빌드 및 번들링 오류 해결.
- **독 버튼(GameControlBar) UI 최적화**: 하단 독 제어 바 버튼 글씨 크기를 단계적으로 조정하여 가독성 및 세련미 향상 (`17.28px`).
- **선수 카드 득점/감점 버튼 UI 조정**:
  - 감점/득점 버튼 텍스트 크기 20% 축소 (감점 `16px`, 득점 `17.6px`).
  - 터치 편의성을 위해 감점/득점 버튼 세로 패딩(크기) 10% 확대.
- **선수 관리 스크린 개편**: 선수 등록 모달 카드 내 핸디 점수 조절(-/+) 버튼을 원형 및 절반 크기로 슬림화하여 직관적 UI 제공.
- **작업 규칙 업데이트**: `AGENTS.md`에 작업 완료 후 `README.md` 변경 내역 자동 동기화 규칙 추가.
- **스코어 점수 텍스트 극대화**: 카드의 상하 수직 여백/마진을 최소화하고 폰트 크기를 `280px` 수준으로 대폭 확장하여, 경기 중 점수 숫자 텍스트가 카드 공간 상하좌우 전체를 꽉 채우도록 개편.
- **경기 시간 타이머 시인성 전 테마 완벽 확보**: 테마 2(라이트 모드) 및 테마 3(스포츠 네온 모드) 등 밝은 배경에서도 눈부심 없이 한눈에 또렷하게 보이도록 타이머 배경에 고대비 딥 다크 칩 배지(`Deep Contrast Dark Chip`)를 적용하여 비비드 네온 옐로우(`#FFD600`) 시인성 전면 강화.
- **상단 헤더(TopBar) 레이아웃 위치 및 타이머 간소화**: 경기 시간 타이머를 상단 중앙(Center) 영역으로 이동하고 불필요한 '경기 시간' 라벨 텍스트를 제거하여 타이머 숫자만 시원하게 정돈, 우측(Right) 영역에 이닝 표시 배지를 구성.
- **목표 점수 다이얼 키패드 입력 모달 개편**: 경기 시작 전 선수 카드 목표 점수 클릭 시 3x4 다크 메탈릭 숫자 키패드 팝업(`HandicapKeypadModal`)이 활성화되며, 모달 오픈 시 기초값 `0`으로 시작하여 번거로운 지움 과정 없이 숫자가 바로 실시간 반영 및 '확인' 처리되도록 개선.
- **선수 카드 하단 스탯 바 '최근 득점' 표시 구현**: '이번 이닝' 좌측에 '최근 득점' 영역을 추가하고, 이닝이 경과하더라도 무득점 공타 턴에는 점수를 리셋하지 않고 가장 최근 점수 변동(득점)이 있던 이닝 수치를 계속 노출하도록 개편.
- **목표 점수 순차 다이얼 입력 및 키패드 UI 개편**: 경기 시작 시 목표 점수가 0점인 선수가 있을 경우 첫 선수부터 순차적으로 다이얼 키패드를 연결하여, 상단에 선수의 이름(`[김당구] 선수 목표 점수`)을 직관적으로 명시하고 '다음' ➔ '확인' 버튼 흐름으로 손쉽게 연속 입력되도록 구축.
- **오류 수정**: `StartLandingScreen` 컴포넌트에 누락되었던 `Modal` 모듈 및 `styles` 선언 구문을 완벽 복구하여 런타임 오류 해결 및 코드 안정화.
- **경기 시간 타이머 포맷 확장**: 경기 시간 타이머 표시 시 기존 분:초 방식에서 항상 시:분:초(`HH:MM:SS`, 예: `00:05:30`)가 명확히 표출되도록 개편.
- **메인 스코어 3D 카드 입체 회전 애니메이션 전환**: 득점/감점 수치 변경 시 아날로그 당구 스코어보드가 입체적으로 찰칵 뒤집히는 3D 카드 플립(`3D Perspective Flip`) 연출을 적용하여 손맛과 시각적 몰입감 극대화.
